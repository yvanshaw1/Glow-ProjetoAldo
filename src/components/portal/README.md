# `src/components/portal/` – Componentes do portal

Componentes das telas do visitante e do cliente, em subpastas por módulo: `layout`, `auth`, `catalog`, `clients`, `vehicles` e `appointments`.

## Vai aqui

- as subpastas de módulo; cada componente na pasta do módulo a que pertence

## Não vai aqui

- componentes do painel (→ `src/components/admin/`)
- componentes usados também pelo painel (→ `src/components/shared/`)
- arquivos soltos nesta pasta, fora de um módulo
