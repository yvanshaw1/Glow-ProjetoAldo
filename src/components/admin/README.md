# `src/components/admin/` – Componentes do painel

Componentes das telas do funcionário, em subpastas por módulo: `layout`, `dashboard`, `appointments`, `catalog`, `clients`, `vehicles`, `staff`, `roles` e `settings`.

## Vai aqui

- as subpastas de módulo; cada componente na pasta do módulo a que pertence

## Não vai aqui

- componentes do portal (→ `src/components/portal/`)
- componentes usados também pelo portal (→ `src/components/shared/`)
- controle de acesso: esconder um botão não protege nada; quem decide é a API (RS008)
