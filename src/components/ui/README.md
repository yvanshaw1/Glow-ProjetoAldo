# `src/components/ui/` – Componentes base do shadcn/ui

Botão, campo, seleção, diálogo, tabela, abas, etiqueta, calendário, aviso (toast) e o formulário integrado ao React Hook Form, gerados pela CLI: `npx shadcn@latest add <componente>`.

## Vai aqui

- componentes gerados pelo shadcn, com ajustes de variante ou de tema quando necessário

## Não vai aqui

- componentes de negócio (→ `shared/`, `portal/` ou `admin/`)
- lógica, chamadas à API ou textos do sistema
- cores fixas: o visual vem das variáveis do tema em `src/app/globals.css`
