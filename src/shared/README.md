# `src/shared/` – Código do navegador e do servidor

O que precisa ser igual nos dois lados: validação, formatação, catálogo de erros, constantes e tipos da API.

## Vai aqui

- `validation/`, `format/`, `errors/`, `constants/` e `api/`

## Não vai aqui

- imports de `src/server/`, do Supabase ou de `server-only`
- leitura de `process.env`
- componentes React
