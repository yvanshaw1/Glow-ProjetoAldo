# `src/app/(admin)/` – Grupo do painel

Grupo de rotas do painel administrativo. Só contém a pasta `admin/`, que dá o prefixo `/admin` às páginas.

## Vai aqui

- a pasta `admin/`

## Não vai aqui

- páginas fora de `/admin`
- componentes (→ `src/components/admin/`)
