# RN009 – Precificação

Os serviços principais e complementares têm o valor definido por porte, com um valor para cada porte (P, M, G e GG), aplicando-se o do porte do veículo do agendamento, ou por valor fixo, igual para qualquer veículo. O serviço adicional tem sempre valor fixo. Todo valor de serviço deve ser maior que zero.
