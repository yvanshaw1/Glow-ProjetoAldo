# RN019 – Cancelamento

O agendamento pode ser cancelado enquanto não estiver em execução: pelo cliente, quando estiver “Agendado”; pelo funcionário, quando estiver “Agendado” ou “Em espera”.

## Onde se aplica

- Requisitos: [RF030](requisitos.md), [RF054](requisitos.md)
- Casos de uso: [UC07](UC07-acompanhar-agendamentos.md), [UC12](UC12-atualizar-status-do-agendamento.md)
