# docs/plataforma/ – Plataforma

O que vale para o sistema inteiro: visão geral e stack, requisitos não funcionais, segurança, formatos dos dados, exclusão lógica e infraestrutura.

Leia só o arquivo do tema da tarefa; estes módulos valem para todos os assuntos. Para achar um identificador em qualquer assunto: `docs/**/RN0xx-*.md`, `docs/**/UCxx-*.md` ou busca pelo ID em `docs/*/requisitos.md`.
