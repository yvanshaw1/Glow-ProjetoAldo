# RN026 – Desativação

O funcionário desativado não acessa o painel administrativo, e o cargo desativado não pode ser atribuído a funcionários.

- Requisitos: [RF037](../acesso/requisitos.md), [RF081](requisitos.md), [RF083](requisitos.md)
