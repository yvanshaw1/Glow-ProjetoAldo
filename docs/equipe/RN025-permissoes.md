# RN025 – Permissões

As permissões correspondem às páginas do painel administrativo: dashboard, agendamentos, serviços, clientes, funcionários e configurações. Cada permissão exibe o link da respectiva página na barra de navegação do painel e dá acesso completo às suas funções (consultar, criar, editar e excluir). Todo cargo deve conceder ao menos uma permissão.

- Requisitos: [RF036](../acesso/requisitos.md), [RF082](requisitos.md)
- Casos de uso: [UC21](UC21-gerenciar-cargos-e-permissoes.md)
