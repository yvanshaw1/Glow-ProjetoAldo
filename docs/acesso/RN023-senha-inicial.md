# RN023 – Senha inicial

As contas de clientes e de funcionários criadas pelo painel administrativo têm a senha inicial definida no próprio cadastro, pois o MVP não realiza envio de e-mails. Essa senha deve ser trocada pelo titular no primeiro acesso (RS004).
