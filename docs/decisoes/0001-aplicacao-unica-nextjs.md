# 0001 – Uma única aplicação Next.js para portal, painel e API

## Decisão

Uma única aplicação Next.js para portal, painel e API.

## Alternativa descartada

Dois frontends e um backend em projetos separados.

## Justificativa

Um só repositório, uma só linguagem e uma só publicação. As duas interfaces continuam separadas por grupos de rotas e layouts próprios.
