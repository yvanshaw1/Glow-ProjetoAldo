# 0004 – Supabase para banco, autenticação e arquivos

## Decisão

Supabase para banco, autenticação e arquivos.

## Alternativa descartada

Banco e autenticação próprios.

## Justificativa

Entrega PostgreSQL, guarda segura de senhas, sessões e armazenamento de arquivos em um único serviço gratuito, sem código de infraestrutura.
