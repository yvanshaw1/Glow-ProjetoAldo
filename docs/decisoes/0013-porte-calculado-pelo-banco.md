# 0013 – Porte calculado pelo banco a partir do tipo

## Decisão

Porte calculado pelo banco a partir do tipo.

## Alternativa descartada

Porte gravado pela aplicação.

## Justificativa

O porte nunca diverge do tipo, e um novo tipo de veículo exige apenas incluir a sua correspondência (RN002).
