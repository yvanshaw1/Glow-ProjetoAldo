# 0027 – Formulários com React Hook Form

## Decisão

Formulários com React Hook Form.

## Alternativa descartada

Estado dos formulários controlado manualmente.

## Justificativa

Validação campo a campo com os mesmos esquemas Zod, preservação dos dados entre as etapas do agendamento e menos código repetido nos formulários do portal e do painel.
