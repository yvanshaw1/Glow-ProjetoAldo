# 0002 – API em rotas do próprio Next.js

## Decisão

API em rotas do próprio Next.js.

## Alternativa descartada

Funções em ambiente de execução separado ou servidor dedicado.

## Justificativa

Dispensa um segundo ambiente de execução e um segundo processo de publicação, e permite compartilhar tipos e validações com a interface.
