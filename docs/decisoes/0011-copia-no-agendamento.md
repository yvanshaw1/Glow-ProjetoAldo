# 0011 – Cópia dos dados no agendamento

## Decisão

Cópia dos dados no agendamento.

## Alternativa descartada

Consulta dos dados sempre nos cadastros atuais.

## Justificativa

O agendamento permanece como foi feito, como uma ordem de serviço: mudanças de preço, de nome de serviço ou de dados do veículo e do cliente não alteram o histórico nem a receita apurada (RN037).
