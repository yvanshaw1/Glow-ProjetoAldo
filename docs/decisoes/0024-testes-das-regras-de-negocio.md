# 0024 – Testes automatizados apenas das regras de negócio

## Decisão

Testes automatizados apenas das regras de negócio.

## Alternativa descartada

Testes de interface de ponta a ponta.

## Justificativa

As regras de preço, status e data concentram o risco de erro; os fluxos de tela são verificados manualmente, conforme a Documentação de Desenvolvimento com IA.
