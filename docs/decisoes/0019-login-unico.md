# 0019 – Página de login única

## Decisão

Página de login única.

## Alternativa descartada

Páginas de login separadas para o portal e para o painel.

## Justificativa

Um só formulário e uma só rota de autenticação; o perfil da conta define o destino após o login (RN029).
